# Plan de demostración técnica - Capítulo 0

## Objetivo
Presentar las principales funcionalidades de la aplicación
mediante un recorrido práctico durante la defensa final.

## Duración prevista
Ocho minutos de demostración.

## Secuencia propuesta

### Minuto 0 a 1: Inicio de sesión
- Mostrar el acceso mediante Firebase Authentication.
- Ingresar a la aplicación.
- Presentar la pantalla principal.

### Minuto 1 a 3: Biblioteca
- Explorar libros disponibles.
- Mostrar las obras gratuitas.
- Abrir una obra y utilizar el lector digital.

### Minuto 3 a 5: Writer
- Mostrar la creación de historias.
- Presentar la organización por capítulos.
- Explicar los borradores y la publicación.

### Minuto 5 a 7: Gemini
- Realizar una consulta literaria.
- Mostrar una búsqueda bibliográfica.
- Explicar el manejo de respuestas y errores.

### Minuto 7 a 8: Cierre
- Presentar el perfil del usuario.
- Resumir las principales integraciones.

## Preparación
Antes de presentar, comprobar la conexión a internet,
el acceso al backend y la disponibilidad de las cuentas
de demostración.

Mantener una alternativa visual para explicar las
funcionalidades si un servicio externo no responde.

## Consideración
Este documento corresponde a una propuesta de recorrido
y no constituye evidencia de una demostración ya realizada.
