# Fase 3 - Capítulo 0

## Proyecto
Capítulo 0 es una aplicación orientada a la lectura, comunidad y creación literaria.

## Tecnologías
Frontend: Flutter y Dart. Backend: Spring Boot. Base de datos: PostgreSQL.

## Autenticación
La autenticación de usuarios se realiza mediante Firebase Authentication.

## Integraciones
El proyecto integra servicios externos para catálogo de libros y funcionalidades complementarias.

## Evidencias
Las evidencias, documentos y presentaciones finales se encuentran organizados dentro de las carpetas de la Fase 3.

## Estado del proyecto
El proyecto se encuentra en su etapa final de integración, pruebas, documentación y presentación.
