# Frontend y experiencia de usuario - Capítulo 0

## Participación en el desarrollo
Durante el proyecto participé en el desarrollo y
mejoramiento de las interfaces de la aplicación Flutter.

## Pantallas trabajadas
- Inicio y descubrimiento de libros.
- Biblioteca personal.
- Perfil y configuración.
- Puntos Lectores.
- Writer y creación de historias.
- Integración visual del chat Gemini.

## Experiencia de usuario
Se trabajó en mantener una identidad visual coherente
entre las distintas pantallas.

También se revisó la navegación, la adaptación a
distintos tamaños de pantalla y la visualización de
portadas, tarjetas y formularios.

## Aprendizajes
Este trabajo permitió reforzar conocimientos de
Flutter, organización de componentes, navegación
y validación de interfaces.

También permitió comprender la importancia de
mantener una experiencia consistente entre módulos
desarrollados por distintos integrantes.
