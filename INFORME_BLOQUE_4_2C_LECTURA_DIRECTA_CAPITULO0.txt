2. FORMATOS Y VALIDADORES EXISTENTES
Gutendex entrega un mapa MIME -> URL en formats.
La documentación contempla text/plain, con o sin parámetros de charset,
además de HTML y EPUB. No todos los formatos declaran UTF-8:
text/plain por sí solo no demuestra esa codificación.

El modelo actual reconoce EPUB, HTML y texto plano; gutenbergResource exige:
- HTTPS.
- Host exacto gutenberg.org o www.gutenberg.org.
- Puerto 443 y ausencia de credenciales.
- Sin espacios, controles ni barras inversas en la URL.
Estos controles son de seguridad sintáctica; no comprueban autorización
de acceso, licencia territorial, CORS, integridad del texto ni edición.
Tampoco vinculan de forma suficiente cualquier ruta de texto con el ID.

book.source genera la ficha canónica:
https://www.gutenberg.org/ebooks/{id}
La ficha ya la muestra mediante SelectableText.
No se modificaron modelos, validadores ni URLs existentes.

Fuente de contrato de metadatos:
https://gutendex.com/
Gutendex se documenta como API de metadatos; una URL en formats no constituye
por sí sola una licencia de contenido o un acuerdo de acceso al servidor.

5. IMPEDIMENTOS PARA HABILITAR LA LECTURA DIRECTA
En Web, recibir un HTTP 200/206 en un cliente de consola no significa que
Flutter Web pueda leer el cuerpo desde otro origen. No se confirmó CORS
utilizable para el origen de prueba en ninguno de los dos candidatos.
No se utilizaron proxies, modo no-cors, reescritura de cabeceras, simulación
de Referer ni desactivación de seguridad para eludir esa restricción.

En Android no se aplica la misma política de origen del navegador, pero
permanecen las condiciones de acceso, derechos y validación de identidad.
No se habilitó una descarga parcial solo para Android dando por resueltas
las condiciones de la fuente.

Además, una asignación de mirror no debe hacerse sustituyendo un hostname
o adivinando un nombre de archivo: las colecciones principal y generada
pueden usar estructuras y versiones distintas. Coincidir en longitud o título
no prueba que sea la misma edición.
No se creó una lista permisiva de hosts ni un servicio con autorización fingida.
