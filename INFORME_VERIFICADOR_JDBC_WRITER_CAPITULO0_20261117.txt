3. QUÉ COMPRUEBA EL VERIFICADOR REAL
- Presencia de DB_URL, DB_USERNAME y DB_PASSWORD, sin imprimir sus valores.
- URL JDBC PostgreSQL de Neon, TLS y ausencia de credenciales embebidas/opciones inseguras de logging.
- Conexión y autenticación mediante DriverManager.
- Transacción con readOnly=true y autoCommit=false.
- Confirmación en PostgreSQL de transaction_read_only=on.
- SELECT 1.
- Existencia de public.flyway_schema_history.
- Registro y éxito de V10, si existe ese historial.
- Existencia de public.writer_stories.
- Rollback y cierre de conexión antes de imprimir el resultado exitoso.
No imprime URL, usuario, contraseña, token ni el mensaje original de un error JDBC. Ante errores SQL comunica solamente SQLState validado.
No utiliza GOOGLE_BOOKS_API_KEY: no es necesaria para comprobar Writer/Neon.

4. COMANDO EXACTO PARA TU POWERSHELL ACTUAL
Ejecutar estando dentro de backend, en la terminal que tiene las credenciales:

mvn -o "-Dtest=WriterNeonReadOnlyTests" "-Dwriter.jdbc.check=true" test

No ejecutar desde una terminal nueva sin las variables. No añadir credenciales al comando ni usar Maven -X.
Sin writer.jdbc.check=true, el test real se omite; una omisión NO demuestra conexión.
